Existing records stay at their established paths to preserve references. Numbered guides, runtime contracts, technical-approach decisions, owner-review handoffs, UI verification reports and slice documents are historical/planning records rather than additional current setup guides. Candidate hashes and recorded results apply only to the identified artifacts. Technical checks do not establish player acceptance.

Generated captures, exact exports and associated evidence are retained separately under `evidence/`; most are not distributed with the repository. Required executable test inputs are in `tests/fixtures`, with provenance. Historical records and binary artifacts are not rewritten to describe newer source.

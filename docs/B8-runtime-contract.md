# B8 identity, presentation and safe-walking contract

Defined before runtime edits. B8 extends the B7 validator; requires `experience_version: 1`, `character: {name, appearance}`, and `facing` (toward/away/left/right). Existing fields and exact accounting retain their meaning. Defaults: Alex, amber. Appearance IDs amber, teal, plum tint clothing only and have no mechanical effects. Name is trimmed, limited to 32 Unicode code points, controls and directional-format controls removed, blank becomes Alex. Name is literal text, never markup or a file path. No biography beyond an ordinary shopping trip interrupted by takeover.

Separate `dev-state/B8-practice-v1`, override `B8_SAVE_DIR`. Every fresh Start creates a generated session directory. A successful first save updates a current-session pointer; former session snapshots remain untouched. Continue selects the last saved session; no B7 or earlier scanning/migration. Session names are generated independently of character input. Malformed snapshots and immutable recovery mechanics remain inherited; no reset-on-inconsistency. Preferences are stored separately from chapter snapshots. Queues/history never replay.

Safe walking is explicit, transient and visible. Only a cleared relay yard qualifies. It permits ordinary one-cell walking on unenergized floor without spending or refreshing AP, advancing rounds, acting for enemies or consuming guard/resources. It stops before live floor, blocked paths, new location, Stop, pause, load or failed persistence. Dash and ordinary walking retain costs. Explicit route selection and physical north passage remain required. No unseen End turn. Combat tuning and eight-material report remain B7 defaults pending measured review.

## Delivered persistence details

`experience_save.gd` validates identity before delegating to the B7 authorities. B7's unopened expedition dictionary was found to compare parsed JSON floats strictly against integral defaults. B8 normalizes only already-validated integral expedition counters in a disposable validation projection. It changes neither resources nor source snapshot bytes. Early power-choice saves are now included in exact new-process Continue checks. No old namespace is scanned or migrated.

Fresh Start uses `session-<unix-seconds>-<monotonic-microseconds>`. The actual character name is never used in a path. A successful snapshot marks the character saved and atomically updates `current-session.txt` through `current-session.tmp`. If the snapshot succeeds but the pointer fails, gameplay keeps that durable outcome; Save and quit refuses to exit and explains Retry/Earlier characters. It does not roll back already durable resources. Earlier characters loads only B8 session directories, using their valid latest snapshot. Continue from a new, wholly unsaved character selects the previous saved session. A malformed saved session uses inherited latest-valid recovery, not an invented reset.

Facing is toward/away/left/right; at a committed movement boundary it derives from the actual destination before animation. Apply restores it before rendering. Jacket recoloring is a torso shader using the retained illustrated rig; head/hands and mechanical effects are unchanged. Preferences (`presentation.cfg`, large text) remain outside chapter state. Font fallback uses macOS system fonts, including Arial Unicode MS, without copying or redistributing them.

Current response is pinned, with explicit History disclosure for long text. Walking arrivals replace earlier interruption text; per-step and generic completion bookkeeping remain in History. Help pauses and stops future plans, then restores command focus. Safe walking remains transient, never saved or silently resumed. Its free-step implementation commits existing state atomically, preserves AP/guard/round/funds, checks each real grid cell, and uses the same physical party route and rescue semantics.

No gameplay damage, upgrade, care or reward numbers changed. Improved weave remains a deliberate preparation payoff: it can absorb a two-pressure pulse, while companion conditions and live-floor exposure remain relevant. See the balance/review record for measured route inputs and limitations.

## Implementable experiment contract

All numbers and local rules below are adjustable engineering hypotheses, not confirmed creative design. A compact 12 × 7 floor grid with 64-pixel steps preserves positional decisions and makes costs inspectable. Reuse the S02 illustrated actors, room textures and cabinet props in a separate tactical scene; VIS-001 stays available.

- Start in a safe demonstration space. Preview blast, shield and dash individually with descriptions and animation; choose one explicitly to enter. Demonstration never spends encounter AP or changes selected power. No permanent class.
- Player starts at (2,5), creature at (9,3), control at (10,1), with 6 health each. Player acts first with 4 AP. Four-way movement costs 1 AP per adjacent cell; dash costs 1 AP for exactly two straight cells. No diagonal movement, occupied cells, wall crossing or corner cutting. Click a cell to commit the selected action. Right click or Cancel drops targeting at no cost.
- Common actions: move; bolt (2 AP, 2 damage, Euclidean range 4 cells, clear line of sight); use the nearby control (1 AP, cardinal adjacency) to lower creature health by 2 once. This single shared attack gives shield/dash an offensive path; the one-use control makes reaching a place useful without starting progression.
- Selected powers: force blast (2 AP, 3 damage, range 3, clear sight); protective shield (1 AP, absorbs the next 2 damage, expires after the next creature turn); short dash (1 AP, two clear cells in a cardinal direction). No power cooldowns or extra progression.
- Actions animate while input is locked. Invalid targets/AP/turns return visible feedback and change no game state. Key repeat is ignored. At zero AP the player explicitly presses End turn; unused AP is discarded. No automatic end-turn surprise.
- Creature alternates approach and a held preparation. It approaches up to two cardinal cells using bounded BFS around obstacles, then crouches and draws back away from a fixed adjacent strike cell. On the next enemy turn it lunges into that same direction and damages the player there for 3; moving away can make it miss. No intent text or exact-action floor overlay. If not adjacent after approach it continues approaching next turn. No route means it waits and returns control. Pet follows autonomously, has no collision layer or tactical occupancy, damage or AP.
- Success: creature health reaches zero; actions stop and success is saved. Defeat: player health reaches zero; show defeat and load actual latest supported save after a short paused-aware interval. If none is usable, remain visibly defeated with a return-to-demonstrations option; never silently substitute reset.
- Persistence: dedicated project development directory `dev-state/S03/`, outside runtime assets. Append immutable numbered JSON snapshots via temporary file then atomic rename. Auto-save after choice/encounter start and success only (avoid replacing a safe retry point each turn). Manual save supports any idle player decision boundary, including partially spent AP, shield and held creature preparation. No save during animations, enemy turns, pause or defeat; UI states the restriction. Persist selected power, actor cells, health, AP, shield, creature preparation/strike cell, control use, turn number and success. Pet resumes near player; transient animation phase is not saved. Latest means greatest valid sequence across manual/autosaves. Validate all fields and semantic bounds before applying; skip interrupted temporary files and visibly report malformed/unsupported snapshots with fallback to latest valid. Existing files are preserved. Tests use disposable directories. Reset returns to demonstrations without deleting saves; loading is explicit and ordinary defeat uses the same loader.
- Explicit Escape pause freezes actor/effect/enemy/retry timers and rejects game actions, save/load/reset. Focus loss also pauses this separate encounter; resuming is explicit. No offline progression.

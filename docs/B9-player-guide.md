# Space Opera RPG Personal Beta — Mac guide

Open **Space Opera RPG Personal Beta.app** from your Applications folder. This app includes the game engine and chapter; it needs no Godot editor, terminal, checkout or network connection. This personal candidate targets Apple Silicon and has been tested only on the owner's macOS 27.0 Mac. Minimum content window: 1152×882.

Enter a name, choose an amber, teal or plum jacket, and select Start new chapter. Blank names become Alex; names are limited to 32 Unicode code points. Appearance does not change statistics. Continue restores the last saved character; Earlier characters selects another saved session. Starting a character preserves prior sessions.

Type an intention and press Return, or choose a visible action. Try `look around`, `inspect package`, `go to package`, or `move 2 up and 3 right`. Follow the current objective through shelter, preparation, the relay expedition, core recovery and the hub report. Home and local care remain usable afterward. Help explains named actions; History retains full responses; Text + enlarges the main text. Click the world to use direct movement. Stop cancels future work; Escape pauses. Focus loss pauses play; resume deliberately.

In danger, spend AP and explicitly End turn. The north range is harmless practice; the breach is an optional repeatable danger; the east barrier starts the full expedition. Retreat returns your joined party. Rest heals the protagonist; companions need explicit paid or free attended care at the shelter desk. There is no permanent pet or recruit death. In a cleared yard, `walk safely` enables free steps along clear dry floor and stops before live floor. The live route still carries risk.

Use **Save and quit** in the pause menu, then open the app and Continue. If saving fails, keep the app open, read the message, and retry. If the chapter saved but Continue selection failed, the durable snapshot remains: retry Save and quit or choose the character through Earlier characters after relaunch. Never delete recovery files as a routine fix.

## Your data

Saves and preferences live outside the app at:

`~/Library/Application Support/Space Opera RPG Personal Beta/chapter-v1/`

Each generated `session-*` directory contains immutable snapshots. `current-session.txt` selects Continue; `presentation.cfg` stores larger-text preference separately. Character names are never filenames. Replacing or moving the app does not move or erase this folder. Do not run two copies against the same session. Existing B8/development saves remain separate; there is no automatic discovery or migration. B8-format compatibility was checked only with disposable synthetic specimens.

## Installation and support boundary

The retained ZIP contains the exact signed app. Unzip it with Archive Utility and place the app in your personal Applications folder. The delivered local copy is ad-hoc signed, without a Developer ID or notarization; Gatekeeper assessment rejects it. Local Finder launch and a successful code-signature check do not establish trust for downloaded/public distribution. If macOS blocks a transferred copy, stop and record the message; do not disable security or strip quarantine. This candidate is for local personal use, not publication.

Presentation is intentionally silent. English command interpretation is bounded, cutout motion and pet articulation are simple, and tall actors can obscure the pet near doorways. Text + does not enlarge compact world/header labels. Representative accented Latin, Chinese, Greek and Cyrillic characters use local system-font fallback; arbitrary scripts and emoji are not comprehensively supported. Screen-reader usability and other Macs/OS versions remain unqualified.
